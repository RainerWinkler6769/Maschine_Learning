# Grundlagen-Testpaket – Alle Versionen

Dieses Verzeichnis enthält 4 gleichwertige Test-Versionen (A, B, C, D) für Grundlagen (KI/ML/Python). Sie eignen sich für Nachschreiber, parallele Kurse und unterschiedliche Lerngruppen.

---

## Allgemeine Eigenschaften aller Versionen

- **Gesamtpunkte:** 25 Punkte
- **Gewichtung:** 70% Theorie (17,5 Pkt.), 30% Praxis (7,5 Pkt.)
- **Bearbeitungszeit:** 45–60 Minuten (Empfehlung)
- **Format:** Handschriftlich lösbar + optional Syntaxhilfe
- **Struktur:**
  - **Teil A (Theorie):** A1 (Begriffe), A2 (Ansätze vergleichen), A3 (Daten/Training), A4 (Menge/Qualität)
  - **Teil B (Praxis):** B1 (Datenverarbeitung, Modelltraining, Evaluation)

---

## Lernziele (alle Versionen)

1. KI, Machine Learning, Deep Learning unterscheiden
2. Regelbasierte vs. datengetriebene Systeme vergleichen
3. Trainings- und Testdaten richtig trennen
4. Labeled/Unlabeled Data definieren und einordnen
5. Einfluss von Datenmenge und -qualität bewerten
6. Python-Workflow umsetzen (Laden, Statistiken, ML-Modell, Evaluation)

---

## Verwendungsszenarien

- **Nachschreibetermine:** Unterschiedliche Versionen für verschiedene Schüler
- **Parallele Kurse:** Jeder Kurs erhält eine andere Version
- **Qualitätssicherung:** Cross-Überprüfung der Lernziele über alle Versionen

## Notizen zur Durchführung

- **Syntaxhilfe:** Die Syntaxhilfe ist optional und darf bei handschriftlicher Lösung als Orientierung genutzt werden.
- **Bewertung:** Fachlogik geht vor Syntax-Perfektion
- **Pseudocode:** Strukturierter Pseudocode ist vollwertig anerkannt, wenn alle Schritte vorhanden sind.
